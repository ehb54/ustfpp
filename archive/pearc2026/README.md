# PEARC 2026 archive

This directory contains the preservation record for the 2026
paper, *Evaluating Deep Learning-Based Performance Prediction for UltraScan
Workflows Under Temporal and Observability Constraints*.

## Final structure

- `publication/` - paper citation/link, final presentation, and correction
  notice; the ACM PDF is not stored in the repository
- `datasets/` - the scrubbed 2026 replication package and manifest
- `workflow/` - preprocessing, grid-search, analysis, simulation, and paper-output
  scripts with the configurations used in 2026
- `results/` - selected models, aggregate grid-search metrics, and final tables
  and figures

## Migration status

The presentation, correction notice, scrubbed datasets, dated model-building
snapshot, and analysis source are in their final archive locations. The dataset
package has been verified, and the ACM-published PDF is intentionally excluded.
Results have been curated into a compact final record: selected models,
aggregate metrics, run log, paper-facing tables, and final figures. The former
bulk copies were verified as redundant and removed.
