# PEARC 2025 archive

This directory contains the preservation record for the 2025
paper, *Optimizing UltraScan Job Scheduling with Deep Learning-Based Performance
Prediction*.

## Final structure

- `publication/` - paper citation/link and final presentation; the ACM PDF is
  not stored in the repository
- `datasets/` - the scrubbed 2025 replication package and manifest
- `workflow/` - preprocessing, feature-analysis, grid-search, and evaluation
  scripts with the configurations used in 2025
- `results/` - compact evidence supporting the reported results

## Migration status

The presentation, scrubbed datasets, and best available paper-era workflow are
in their final archive locations. The dataset package has been verified, and the
ACM-published PDF is intentionally excluded. Result curation remains incomplete.
The two candidate 2DSA populations must remain clearly distinguished because the
original selected-model artifact is unavailable.

No source in this archive should be described as the exact model-training input
unless a preserved run artifact establishes that provenance.
